# 要件定義

## 背景

Webページ、ネイティブアプリ、Windows、Android、その他アプリのデザインガイドラインを辞書的に学べる。レイアウト、入力、ナビゲーション、アクセシビリティ、コンポーネント、OS別慣習、歴史的背景、関連ガイドライン、トレードオフをタグで整理する。

## 課題

UI設計では、OSやプラットフォームごとの慣習、アクセシビリティ、実装都合が混ざり、どのガイドラインを優先すべきか判断しづらい。

## ユーザー価値

- 代表データを入力し、必須不足、警告、正常完了を同じ評価軸で確認できる。
- closed alpha 段階でも手順、責務、QCDS、release evidence を追える。
- Web、Windows、Android、制作ツール系UIを横断し、場面別に守るべき慣習と崩してよい理由を学べる。

## MVP外では終わらせない範囲

- MVP後の UI/UX polish、責務分割、security/privacy、traceability、docs ZIP、release evidence を含める。
- 手動テストはユーザーが実施できる粒度で残す。
